{{TITLE}}

以 Claude Code 官方文档为视觉基准，让分析、规划和技术报告拥有一致的字体、留白与阅读节奏。

新的报告样式采用文档优先的布局。正文使用 Anthropic Sans，标题使用 Anthropic Serif Display，路径和代码使用 paperMono。字体随文件嵌入，打开报告无需联网。

左侧目录用于浏览章节，正文以标题、段落和表格组织信息。深浅色切换和复制操作均在本地完成。这是一份样式示例，生成正式报告时应替换为实际结论与证据。
